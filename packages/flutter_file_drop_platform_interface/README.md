# flutter_file_drop_platform_interface

Internal platform contract shared by the `flutter_file_drop` façade and its platform implementations.

The interface carries ordered drag lifecycle events, per-item metadata or strings, session-scoped file chunk reads, and resource release. It is not the application API. Application code should depend on [`flutter_file_drop`](https://pub.dev/packages/flutter_file_drop).

Platform implementations must extend `FlutterFileDropPlatform`, register their instance, emit `PlatformDropEvent` values through the `flutter_file_drop/events` event channel, and implement `DropFileHostApi`. Keep item order and session IDs stable through the end of a drop callback.

Native event transport uses an `EventChannel`. Pigeon generates the file chunk and release host API. Event channels are not generated by Pigeon for every supported native language target, so the event DTO remains a small map contract.

This package follows the façade's version.
